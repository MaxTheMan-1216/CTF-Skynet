CTF Challenge

A Linux terminal puzzle game. SSH into each level, find the password, and use it to log in to the next level.

Getting Started

ssh level100@<server> -p 2222

Password: level100

Levels

Level 100 → 101

The password for the next level is stored in a file called readme.txt in your home directory.

Commands: ls, cat

Level 101 → 102

The password is hiding in the home directory — it might not be immediately visible.

Commands: ls -a, cat

Level 102 → 103

The password is stored in a file whose name contains spaces.

Commands: ls, cat (with quoting or escaping)

Level 103 → 104

The password is in one of many files inside data/. Only one file contains human-readable text.

Commands: file, strings, grep

Level 104 → 105

The password is in data.txt, encoded with base64.

Commands: base64, cat

Level 105 → 106

The password is in a file called compressed_data that has been compressed multiple times.

Commands: file, gzip, bzip2, mv

Level 106

You made it! This is the final level.
